# Учёт ЭЭГ-данных (Python + Django + SQLite)

Курсовой проект демонстрирует RAD-подход для быстрой сборки внутреннего сервиса учёта ЭЭГ-исследований на стеке **Python + Django + Django Admin + SQLite**.

## Возможности
- Ведение карточек пациентов и нескольких сеансов ЭЭГ для каждого пациента.
- Хранение метаданных сеанса: схема электродов, частота дискретизации, исполнитель и длительность записи.
- Прикрепление файлов (EDF/отчёты/скриншоты) к сеансу через Django Admin.
- Русифицированный интерфейс админки с быстрым поиском и фильтрами.

## Структура
- `manage.py` — точка входа для служебных команд Django.
- `eeg_registry/settings.py` — настройки проекта, SQLite по умолчанию.
- `eeg_registry/records/` — приложение с моделями пациентов, сеансов и вложений, а также конфигурацией Django Admin.
- `requirements.txt` — список зависимостей (только Django).

## Подготовка окружения
1. Установите зависимости (рекомендуется виртуальное окружение):
   ```bash
   pip install -r requirements.txt
   ```
2. Примените миграции и создайте администратора:
   ```bash
   python manage.py migrate
   python manage.py createsuperuser
   ```

## Запуск
```bash
python manage.py runserver
```
Админ-панель будет доступна по адресу http://127.0.0.1:8000/admin/.

## Тесты
Для проверки базовой логики моделей выполните:
```bash
python manage.py test
```

## Полезные заметки
- Файлы вложений по умолчанию сохраняются в папку `media/eeg_records/`. Путь можно изменить в настройках.
- Для демонстрации достаточно добавить пару пациентов и сеансов через админку, прикрепив тестовые файлы или ссылки.
